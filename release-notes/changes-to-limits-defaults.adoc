= AFX 시스템에 영향을 미치는 ONTAP 제한 및 기본값 변경 사항
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
AFX 시스템에 영향을 미치는 제한 및 기본값 변경 사항에 대해 알아보세요. NetApp은 각 ONTAP 릴리스에서 가장 중요한 기본값 및 제한 변경 사항을 고객이 이해할 수 있도록 지원하기 위해 노력합니다.


TIP: AFX 클러스터의 기능을 확인하려면 NetApp Hardware Universe 및 상호 운용성 매트릭스 도구에서 제공되는 세부 정보를 검토해야 합니다.



[[changes-to-ontap-limits]]
== ONTAP 제한 변경 사항

[cols="1,3,1"]
|===
| 기능 | 제한 변경 | 릴리스에서 변경됨 


| SnapMirror NAS용 활성 동기화  a| 
SnapMirror active sync for NAS는 AFX 플랫폼(4 x 4)에서 지원하는 볼륨 수를 600개로 늘립니다.
| ONTAP 9.20.1 


| SnapMirror 동기식  a| 
SnapMirror 동기 기능은 AFX 플랫폼에서 지원되는 볼륨 수를 400개에서 600개로 늘립니다.
| ONTAP 9.20.1 


| FlexCache 볼륨  a| 
볼륨당 하나의 구성 요소를 사용할 경우 지원되는 FlexCache 볼륨 수는 노드당 2500개, HA 쌍당 5000개로 증가합니다.

원본 볼륨에서 생성할 수 있는 FlexCache 볼륨 수가 200개로 늘어나고, 원본당 쓰기 캐시 수가 50개로 늘어납니다.
| ONTAP 9.20.1 


| 클러스터당 노드 수  a| 
AFX 클러스터는 최대 32개 노드까지 확장할 수 있습니다. 이를 통해 워크로드 및 애플리케이션의 증가하는 요구 사항에 맞춰 AFX 스토리지 시스템을 확장할 수 있습니다. 단, 32개 노드 지원 시에는 일부 기능이 제한될 수 있습니다. 자세한 내용은 NetApp 영업팀에 문의하십시오.
| ONTAP 9.19.1 


| FlexGroup당 볼륨  a| 
FlexGroup의 최대 볼륨 수가 32개 노드에서 512개로 증가했습니다. 이를 통해 AFX 스토리지 시스템이 더 큰 클러스터에 필요한 성능을 완벽하게 제공할 수 있습니다.
| ONTAP 9.19.1 


| SnapMirror 클라우드 지원  a| 
SnapMirror 클라우드에서 지원하는 S3 버킷의 최대 개수가 100개로 증가했습니다. 이를 통해 워크로드 및 애플리케이션에 더 많은 S3 버킷을 생성할 수 있습니다.
| ONTAP 9.19.1 
|===
