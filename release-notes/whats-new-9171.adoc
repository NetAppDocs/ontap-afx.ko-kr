= AFX 스토리지 시스템용 ONTAP 9.17.1의 새로운 기능
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
AFX 스토리지 시스템에서 사용할 수 있는 ONTAP 9.17.1의 새로운 기능에 대해 알아보세요.


NOTE: ONTAP 9.17.1에는 AFX에서 사용할 수 있는 여러 가지 새로운 기능이 있습니다. 이러한 기능 중 일부는 AFX에 특화된 기능이며, 다른 많은 기능은 공통으로 사용되는 제품 기반에서 파생된 것입니다. 아래에 설명된 AFX 기능을 검토하는 것 외에도 https://docs.netapp.com/us-en/ontap/release-notes/whats-new-9171.html["ONTAP 9.17.1의 새로운 기능"^]도 참조하십시오.



[[platforms]]
== 플랫폼

[cols="2,4"]
|===
| 업데이트 | 설명 


| 플랫폼  a| 
다음 NetApp AFX 스토리지 시스템 구성 요소는 관련 지원 기술과 함께 제공됩니다.  이 플랫폼을 통해 통합된 하드웨어 및 소프트웨어 솔루션을 제공하여 고성능 NAS 및 S3 고객의 요구 사항에 맞춰 간소화된 환경을 구축합니다.

* AFX 1K 컨트롤러
* NX224 선반
* Cisco Nexus 9332D-GX2B 및 Nexus 9364D-GX2A 스위치


|===


[[storage-resource-management-enhancements]]
== 스토리지 리소스 관리 향상

[cols="30%,70%"]
|===
| 업데이트 | 설명 


 a| 
xref:../manage-data/monitor-debug-storage.html[AFX 스토리지 시스템 모니터링 및 문제 해결]
 a| 
ONTAP NAS 프로토콜용으로 할당된 ONTAP 클러스터에서 새로 생성된 SVM에 생성된 볼륨에는 기본적으로 파일 시스템 분석(FSA)이 활성화됩니다. FSA는 볼륨이 생성되는 즉시 자동으로 활성화되어 추가 구성 없이 즉각적인 분석 기능을 제공합니다.

|===
