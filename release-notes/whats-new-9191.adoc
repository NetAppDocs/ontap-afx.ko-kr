= AFX 스토리지 시스템용 ONTAP 9.19.1의 새로운 기능
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
AFF 스토리지 시스템에서 사용할 수 있는 ONTAP 9.19.1에 포함된 새로운 기능에 대해 알아보십시오.



[[data-protection]]
== 데이터 보호

[cols="2,4"]
|===
| 업데이트 | 설명 


| link:../administer/additional-ontap-svm.html["ONTAP SnapMirror 액티브 동기화를 사용하여 NAS 보호"]  a| 
SnapMirror 액티브 동기화는 AFX 클러스터(4노드만 해당)에서 NFS 및 SMB를 사용하여 SVM 수준에서 NAS 워크로드를 지원하며, 기본 클러스터에서는 읽기/쓰기 액세스만 허용합니다.

|===


[[networking]]
== 네트워킹

[cols="2,4"]
|===
| 업데이트 | 설명 


| link:../administer/additional-ontap-cluster.html#performance["TCP 성능 개선"]  a| 
ONTAP 9.19.1 버전부터 ONTAP은 PRR과 RACK이라는 두 가지 손실 복구 기능을 ONTAP TCP 스택에 통합하여 손실이 많고 지연 시간이 긴 WAN 링크에서 TCP 데이터 전송 성능을 향상시킵니다.

|===


[[performance]]
== 성능

[cols="2,4"]
|===
| 업데이트 | 설명 


| 교차 파일 순차 읽기(CFSR)  a| 
Cross File Sequential Read는 특정 미디어 및 엔터테인먼트 워크로드에서 읽기 성능을 크게 향상시킬 수 있습니다. 이 기능은 순차적 비디오 프레임을 지능적으로 미리 가져와 비디오 편집 애플리케이션의 처리량을 대폭 개선하고 지연 시간을 줄입니다. 자세한 내용은 link:../administer/additional-ontap-svm.html["AFX 스토리지 시스템 SVM에 대한 추가 관리"]을(를) 검토하십시오.



| 전역 중복 제거  a| 
글로벌 데이터 중복 제거는 ONTAP 데이터 중복 제거를 통해 스토리지 가용성 영역(SAZ) 전체에 걸쳐 공간 절약 효과를 제공합니다. SAZ 내 모든 볼륨에서 중복 데이터 블록을 제거함으로써 스토리지 효율성을 크게 향상시키고 총 소유 비용을 절감할 수 있습니다. 이 기능은 AFX 시스템에서 기본적으로 활성화되어 있으며 관리자 구성 없이 투명하게 작동합니다. 자세한 내용은 link:../administer/additional-ontap-svm.html["AFX 스토리지 시스템 SVM에 대한 추가 관리"]을 참조하십시오.



| 동적 스토리지 효율성  a| 
Dynamic Storage Efficiency는 고성능과 최대 처리량이 요구되는 대규모 워크로드에 맞춰 스토리지 효율성 작업(압축, 중복 제거, 컴팩션)을 지능적으로 최적화합니다. 이 기능은 대용량 쓰기 조건을 자동으로 감지하고 인라인 및 백그라운드 스토리지 효율성 프로세스를 일시적으로 중단하여 피크 부하 시 성능 저하를 방지합니다. 처리량이 정의된 임계값 아래로 떨어지면 스토리지 효율성 작업이 재개되어 수동 개입 없이 절감 효과를 복구할 수 있습니다. 이 기능은 AFX 스토리지 시스템에서 사용 가능하며 별도의 구성 없이 기본적으로 활성화됩니다.

|===

== REST API

[cols="2,4"]

| 업데이트 | 설명 


| Kubernetes 스토리지 오케스트레이션을 위한 균형 배치 개선  a| 
ONTAP 9.19.1은 현재  `/storage/volumes` REST API 엔드포인트에서 사용 가능한 6개의 매개변수를  `/applications/containers` 엔드포인트에 추가합니다. 이 개선 사항을 통해 Kubernetes 스토리지 오케스트레이션을 위한 NetApp Trident를 사용하는 고객은 ONTAP의 기본 균형 배치 기능을 사용하여 볼륨을 생성할 수 있습니다.

[[security]]
== 보안

[cols="2,4"]
|===
| 업데이트 | 설명 


| https://docs.netapp.com/us-en/ontap/anti-ransomware/use-cases-restrictions-concept.html#snapmirroreligible["SnapMirror 기본 볼륨에 대한 ARP/AI 지원"^]  a| 
ARP/AI는 AFX 시스템과의 SnapMirror 동기 관계에서 적합한 운영 볼륨을 지원합니다. ARP/AI는 활성 읽기-쓰기 운영 볼륨에서 실행되어 운영 볼륨 전용 ARP 스냅샷을 생성하고 머신 러닝 기반 랜섬웨어 탐지 기능을 제공합니다.



| link:../administer/additional-ontap-cluster.html["TLS 하드웨어 오프로드 지원"]  a| 
지원되는 이더넷 카드로 전체 클러스터의 전송 계층 보안(TLS) 암호화 및 복호화를 오프로드할 수 있습니다. 이를 통해 CPU 오버헤드가 줄어들고 TLS를 사용하는 시스템의 성능이 향상됩니다.



| link:../administer/additional-ontap-svm.html["TLS v3를 통한 NFS"]  a| 
ONTAP 9.19.1 버전부터 ONTAP은 NFS가 활성화된 SVM에서 전송 중인 NFS 트래픽을 암호화하기 위해 TLS 1.3을 사용하는 NFS over TLS에 대한 온프레미스 지원을 추가합니다. 또한 이 릴리스에서는 LIF별 선택적 상호 TLS 호스트 인증과 일치하는 클라이언트에 대한 비 TLS TCP 액세스를 차단하는 내보내기 정책 제어를 지원합니다.

|===


[[storage-resource-management]]
== 스토리지 리소스 관리

[cols="2,4"]
|===
| 업데이트 | 설명 


| link:../administer/monitor-cluster-performance.html["System Manager는 스토리지 가용성 영역 용량 세부 정보를 지원합니다."]  a| 
System Manager에서 스토리지 가용 영역 용량 세부 정보(공간 임계값, 스냅샷으로 사용된 공간, 데이터 감소 등)를 확인할 수 있습니다. 또한 ONTAP에서 경고 및 위험 알림을 생성할 비율로 공간 사용 임계값을 설정할 수 있습니다.



| link:../administer/additional-ontap-cluster.html["자동 QoS 처리량 상한 증가를 제어하는 기본 설정을 수정하는 기능에 대한 지원이 제공됩니다."]  a| 
QoS 정책 그룹이 단기적인 성능 향상 요구에 대응하여 QoS 처리량 상한을 자동으로 높이는 방식을 제어하는 기본 설정을 수정할 수 있습니다. 이러한 설정은 ONTAP 9.18.1 이하 버전에서는 수정할 수 없습니다.
