= AFX 2K 스토리지 시스템 설치 및 설정 워크플로
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFX 2K 스토리지 시스템을 설치 및 구성하려면 하드웨어 요구 사항을 검토하고, 사이트를 준비하고, 스위치를 설치하고, 하드웨어 구성 요소를 설치 및 케이블링하고, 시스템 전원을 켜고, ONTAP AFX 클러스터를 설정해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"]link:../install-setup/install-setup-requirements.html["하드웨어 설치 요구 사항을 검토하세요"]
[role="quick-margin-para"]
AFX 2K 스토리지 시스템을 설치하기 위한 하드웨어 요구 사항을 검토하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"]link:../install-setup/prepare-hardware.html["AFX 2K 스토리지 시스템 설치 준비"]
[role="quick-margin-para"]
AFX 2K 스토리지 시스템 설치를 준비하려면 설치 장소를 준비하고, 환경 및 전기 요구 사항을 확인하고, 충분한 랙 공간을 확보하고, 장비를 개봉하고, 포장 명세서와 내용물을 대조하고, 지원을 위해 하드웨어를 등록해야 합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["삼"]link:install-switches.html["AFX 2K 스토리지 시스템의 스위치를 설치합니다"]
[role="quick-margin-para"]
캐비닛이나 랙에 Cisco Nexus 9808, 9332D-GX2B 또는 9364D-GX2A 스위치를 설치하십시오. Cisco Nexus 9364D-GX2A 스위치를 사용하는 경우 패스스루 패널 키트를 설치하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"]link:deploy-hardware.html["AFX 2K 스토리지 시스템의 하드웨어 설치"]
[role="quick-margin-para"]
보관 시스템과 선반에 레일 키트를 설치하세요.  보관 시스템을 캐비닛이나 통신 랙에 안전하게 보관하세요.  다음으로, 설치된 레일 위로 선반을 밀어 넣습니다.  마지막으로, 케이블 정리를 위해 보관 시스템 뒷면에 케이블 관리 장치를 부착합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["다섯"]link:cable-hardware.html["AFX 2K 스토리지 시스템의 컨트롤러 및 쉘프 케이블 연결"]
[role="quick-margin-para"]
하드웨어에 케이블을 연결하려면 먼저 스토리지 컨트롤러 노드를 네트워크에 연결한 다음, 컨트롤러 노드와 스토리지 선반을 클러스터 스위치에 연결합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["육"]link:power-on-configure-switch.html["AFX 2K 스토리지 시스템의 스위치 전원 켜기 및 구성"]
[role="quick-margin-para"]
AFX 2K 스토리지 시스템의 스위치를 켜고 구성합니다. Cisco Nexus 9808, 9332D-GX2B 및 9364D-GX2A 스위치의 구성 지침을 확인하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["일곱"]link:power-on-hardware.html["AFX 2K 스토리지 시스템 전원 켜기"]
[role="quick-margin-para"]
각 저장 선반의 전원을 켜고 컨트롤러 노드의 전원을 켜기 전에 고유한 선반 ID를 지정하여 설정에서 각 선반을 명확하게 식별합니다.
