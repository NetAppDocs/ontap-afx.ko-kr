= AFX 스토리지 시스템 버킷 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFX S3 버킷과 클라이언트 액세스를 관리하는 일환으로 수행할 수 있는 관리 작업이 여러 가지 있습니다.  AFX의 S3 구성 및 지원은 Unified ONTAP 에서 제공하는 것과 동일합니다.  자세한 내용은 Unified ONTAP 설명서를 참조하세요.

ONTAP의 S3 스토리지 지원에 대한 최신 변경 사항 및 업데이트를 숙지하는 것도 중요합니다. 예를 들어, ONTAP 9.19.1 버전부터는 각 S3 사용자별로 두 번째 액세스 키를 생성할 수 있습니다. 이를 통해 기존 액세스 키가 만료되더라도 S3 리소스에 대한 액세스 권한을 유지할 수 있습니다. 또한 조건부 작업(쓰기, 복사, 삭제) 적용을 제어할 수도 있습니다.
